# 🚀 Featured Projects

## 🤖 AI Powered Chat Bot — MERN

A full-stack AI chat application built with production-oriented backend concepts rather than being only a basic AI API wrapper.

**Tech:** `React` `Node.js` `Express` `MongoDB` `JWT` `SSE` `REST APIs`

**Highlights:**
- ⚡ Streaming AI responses using **Server-Sent Events (SSE)**
- 🧠 Persistent conversational sessions and messages with **MongoDB**
- 🔐 **JWT authentication** with HTTP-only cookies
- 🔌 Provider-agnostic architecture for AI integrations
- 🛡️ Rate limiting, CORS, CSRF support, and input validation
- 📤 Session export and conversational memory
- 🧪 Unit testing with a mock AI provider

➡️ **View Repository:** https://github.com/Gurkamalvirk/ai-chat-bot-trial-1
