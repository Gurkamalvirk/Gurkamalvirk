# ⭐ Featured Project

## 🤖 AI Powered Chat Bot — MERN

My primary portfolio project: a full-stack AI chat application built with production-oriented backend concepts rather than only a basic AI API wrapper.

**Tech:** `React` `Node.js` `Express` `MongoDB` `JWT` `SSE` `REST APIs` `JavaScript`

**Highlights:**
- ⚡ Streaming AI responses using **Server-Sent Events (SSE)**
- 🧠 Persistent users, sessions, messages, and prompts with **MongoDB**
- 🔐 **JWT authentication** with HTTP-only cookies
- 🔌 Provider-agnostic architecture for AI integrations
- 🛡️ Rate limiting, CORS, CSRF support, and input validation
- 📤 Session export and conversational memory
- 🧪 Unit testing support with a mock AI provider

➡️ **[Explore AI Chat Bot](https://github.com/Gurkamalvirk/ai-chat-bot-trial-1)**
